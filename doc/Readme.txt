Grow Up Town
小さな町を、大きな暮らしへ。

【起動】
ZIPの内容をすべて展開し、GrowUpTown.exeを起動してください。
同梱ファイルは同じフォルダーに置いたままにします。
Windows x64向けで、配布版には.NETの実行環境が含まれています。
日本語表示にはWindowsのメイリオ、または游ゴシックを使用します。

【はじめての町づくり】
24×24マスの土地と16,000円から始まります。
町の西側入口 [0, 12] へ続く道路沿いに住宅と職場を増やし、
公園や水辺で住環境を整えながら人口500人を目指してください。
目標達成後も町づくりを続けられます。通常5秒で1か月進みます。

【主な操作】
1〜7：道路 / 住宅 / 商業地 / 工業地 / 公園 / 撤去 / 水域
8 / 9 / 0 / T：super住宅商業地 / super工業地 / super工業商業地 / super住宅地
U：ultra複合都市
B / N / G：線路 / 駅 / 森林（40年1月から）
左クリック：建設・撤去
左ドラッグ：道路・線路・水域・森林の連続配置
「スペシャル」：専用ウィンドウから施設を選択（30年から）
L：土地購入（初回1,000,000円、以降500,000円ずつ増加）
Space：時間の停止・再開
F5 / F9：保存 / 読込
F1：操作説明、F2 / F3：左右のパネルの表示切替、Tab：両パネルの表示切替
WASD / 矢印 / 中ボタンドラッグ：カメラ移動
右ドラッグ：回転・見下ろす角度の変更、Shift＋右ドラッグ：カメラ移動
ホイール：拡大・縮小、Home：視点を初期状態に戻す
Alt＋Enter：枠なし全画面とウィンドウ表示の切替
Esc：選択解除・ダイアログを閉じる

【鉄道・森林】
線路は1マス100円・維持費3円/月、駅は2×2マスで4,800円・維持費100円/月。
駅の設置には敷地の1辺に、その辺と平行な直線線路2マスが必要です。
異なる2駅以上を線路で結ぶと、各駅から5マス以内の住宅の住環境＋10、
道路接続済みの商業部分の税収基準額＋20％の効果があります。
十字の線路は直進のみで、交差する縦横の路線はつながりません。
道路と線路を重ねると踏切になり、撤去時には両方を除去します。
3両編成の列車と踏切の演出はゲーム速度に連動し、一時停止中は止まります。
森林は1マス420円・維持費18円/月。道路接続なしで周囲3マスの住環境＋15。
住環境効果の上限は、ほかの施設と合わせて＋25です。

【接続表示と周辺効果】
建設・撤去後の道路・鉄道接続と周辺効果は、まとめて再計算します。
最後の編集から約0.35秒後、または更新予約から約2秒後に計算を始めるため、
表示や収支への反映には少し遅れがあります。時間停止中も更新は進みます。

【保存】
自動保存はありません。終了前にF5で保存してください。
保存は1スロットで、GrowUpTown.exeと同じフォルダーのcity.jsonに上書きします。
次回起動時はF9で読込してください。未保存の町は読込時に置き換わります。
「新しい町」では保存ファイルは消えませんが、その後の保存で上書きされます。
保存形式はVersion 3で、Version 1・2は読み込めません。
以前の %LOCALAPPDATA%\GrowUpTown\city.json は新しい保存先へ手動コピーが必要です。
