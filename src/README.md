# Grow Up Town

C# / Raylib の3D見下ろし型・町建設シミュレーションです。外部画像やモデル不要のプロシージャル描画で、住宅、商業地、工業地、公園を配置できます。

## Visual Studio 2022 で起動

1. Visual Studio 2022 **17.8 以降**と「.NET デスクトップ開発」ワークロード、.NET 8 SDK を用意します。
2. `GrowUpTown.sln` を開き、NuGet パッケージの復元を待ちます（初回はネット接続が必要です）。
3. `GrowUpTown` をスタートアッププロジェクトにして F5 で開始します。

Windows x64 向け。日本語表示に Windows のメイリオ、なければ游ゴシックを使用します。システムフォントの配布は行いません。

## コマンドライン

```powershell
dotnet build GrowUpTown.sln -c Release
dotnet run --project GrowUpTown.csproj -c Release
dotnet run --project GrowUpTown.csproj -c Release -- --self-test
dotnet run --project GrowUpTown.csproj -c Release -- --smoke-test
```

`--self-test` は描画なしで経済・接続・保存等を検証します。`--smoke-test` はウィンドウを8フレーム描画して終了します。環境変数 `GROWUPTOWN_SCREENSHOT` にファイル名（例：`smoke-test.png`）を設定すると終了前にスクリーンショットを出力します。保存先はセーブデータと共通です。パスを指定した場合もファイル名部分のみを使用します。

## シミュレーションのルール

### 年月による建設の解放

以下は画面に表示される年数を基準に、その年の1月に解放されます（開始時は1年1月）。

| 分類 | 解放時期 |
|---|---|
| super住宅商業地・super工業地・super工業商業地・super住宅地 | 5年1月 |
| ultra複合都市 | 10年1月 |
| スペシャル（大公園・スーパーマーケット・物流センター） | 15年1月 |

解放前も左の項目は残り、名称・金額を「？」「¥？」で表示します。項目は無効になり、クリック・ショートカットキー・建設操作からは選択・設置できません。スペシャルの選択ウィンドウも15年まで開けません。解放月に自動で通常の名称・金額と操作が戻ります。道路などの通常施設、土地購入、撤去は開始時から使えます。

保存した年月で解放状態を判定します。以前のセーブに解放前の建物が存在する場合、その建物は保持され、稼働・成長・撤去できますが、新規建設は解放を待つ必要があります。新しい町では再び封印されます。

`GROWUPTOWN_UNLOCK_PREVIEW=1`・`5`・`10`・`15` と `--smoke-test` で各年のメニュー表示を確認できます。既存の建物外観プレビューは、全施設が解放される15年1月から開始します。

画面右側の「今、町に必要なもの」に、住宅・職場・発展条件の案内を常時表示します。建設・撤去・月の経過・読込に応じて更新されます。

- 住宅がない、または職場の発展に必要な人口を収容できない場合は、必要な追加定員と住宅建設を案内します。住宅の空きが少ない場合も表示します。
- 労働人口より雇用枠が少なければ職場不足です。商業地・工業地の追加を案内します。
- 労働人口が雇用枠の55%未満なら、商業・工業の発展に不足する労働者数を表示します。住宅定員が十分なら人口増加を待ち、不十分なら通常住宅を増やす案内になります。
- 道路未接続の建物や幸福度60未満も案内します。商業と工業は共通の雇用条件で判定します。

数値は既存の町の集計値を使い、画面外の区画についても通常のシミュレーションと同じ更新タイミングになります。

- 最初から住宅4棟、商業地、工場、公園、外部接続道路のある小さな町で始まります。所持金は16,000。
- 道路は上下左右で接続します。最初の町の西側入口 **(0, 12)** まで続く道路に、建物が隣接していると稼働します。拡張後も入口は同じ場所です。斜め接続は無効。赤枠は道路未接続です。
- 道路の絵は現在の隣接道路に合わせます。直角の2方向はカーブ、向かい合う2方向は直線、3方向はT字路、4方向は十字路です。隣を建設・撤去すると自動で切り替わります。16接続パターンの共通テクスチャを使用します。
- 通常5秒で1か月進みます。住宅はレベルごとに24人、商業地は16人、工業地は32人の雇用枠を持ちます。住民の55%が労働人口です。
- 雇用と住宅に空きがあり幸福度が保たれると、1棟につき最大4人/月が入居します。道路が切れた住宅や幸福度の低い町からは住民が減ります。
- 幸福度60以上で十分な入居・就業条件を6か月連続で満たすと、建物が自動で成長します（最大レベル3）。人口の目標は500人です。目標達成後も続けられます。
- 公園は距離3以内（縦横の合計）に好影響、工場は悪影響を与えます。高税率・失業・借金も幸福度に影響します。
- 税収は住民税と稼働率に応じた商業・工業税。道路と建物には毎月の維持費がかかります。撤去に返金はありません。
- 資金がマイナスでも時間は進みます。ゲームオーバーはありませんが、建設には費用が必要です。初期の町は黒字で運営できます。
- これは基本動作を備えたシミュレーションです。電力・水道・個別住民の経路探索は対象外で、車は道路上の演出です。

## super建築物

いずれもレベル1で建設し、条件を6か月連続で満たすと最大レベル6まで成長します。通常の建物の最大レベルは3のままです。

| 建築物 | 建設費 | 1レベルあたりの入居定員 | 1レベルあたりの雇用 | 1レベルあたりの維持費/月 |
|---|---:|---:|---:|---:|
| super住宅商業地 | 4,280円 | 96人 | 64人 | 52円 |
| super工業地 | 3,600円 | — | 128人 | 56円 |
| super工業商業地 | 6,200円 | — | 192人（工業128＋商業64） | 88円 |
| super住宅地 | 4,800円 | 192人 | — | 40円 |

クリックしたマスを起点に、X・Zの正方向へ2×2マスを使用します。4マスすべてが購入済みの空き地であれば、土地の区画境界をまたいで建設できます。配置予定の範囲は2×2の枠で表示します。外周のどこかが入口につながる道路に隣接すれば、建物全体が稼働します。占有マスのどこを撤去しても1棟全体を撤去し、費用は40円です。

複合ビルには店舗の入口・庇と上層住宅、大工場には大型屋上設備と3本の煙突を描画します。成長時は階を追加し、既存階の外観を保持します。複合ビルは最大16人/月が入居し、入居率が5/6以上・幸福度60以上・道路接続ありで成長します。大工場は通常工場と同じ就業条件で成長します。商業・工業の税収はそれぞれ1レベルにつき400円・640円を基準に稼働率と税率で変化します。大工場の占有マスは周辺住宅の住環境に悪影響を与えます。

既存のVersion 3セーブはそのまま読み込めます。新しい建物の占有範囲・人口・レベル・外観も保存します。

super工業商業地は、生産と流通を担う複合ビルです。店舗・事務所の壁面、工業用の壁面、搬入口、外付け荷物用リフト、屋上の生産設備・煙突・荷物を組み合わせます。入居枠はなく、工業・商業を合わせた税収基準は1レベルにつき1,040円で、稼働率・税率に応じて変化します。発展条件は道路接続、幸福度60以上、町全体の労働人口が雇用枠の55%以上の状態を6か月連続で満たすことです。周辺住宅への公害はsuper工業地と同じです。流通設備は外観で表現し、商品の生産量・輸送量を個別に計算する機能はありません。

外観検証には、`GROWUPTOWN_SUPER_PREVIEW=1` を設定して `--smoke-test` を実行すると、両建築物のレベル1～6を並べたプレビューを表示します。通常の起動・保存データには影響しません。
`GROWUPTOWN_SUPER_PREVIEW=industry-commerce` ではsuper工業商業地のレベル1～6を表示します。
`GROWUPTOWN_SUPER_PREVIEW=home` ではsuper住宅地のレベル1～6を表示します。

super住宅地はガラス面、各階のバルコニー、エントランスの植栽、屋上設備を備えたタワーマンションです。1レベルにつき2段の窓・バルコニーを追加し、レベル6で定員1,152人になります。入居は最大32人/月で、住宅と同様に雇用の余裕・幸福度・住環境の影響を受けます。道路接続・幸福度60以上・入居率5/6以上を6か月続けると成長します。商業機能や雇用枠はなく、周辺の工場からの公害を受けます。

## ultra住宅地＆商業地＆工業地

住宅・商業・工業を一体化した、ひとつの街のようなSF都市ビルです。建設メニューでは「ultra複合都市」と表示し、Uキーでも選択できます。購入済みの空き地3×3マスが必要で、区画境界をまたいで建設できます。建設費は18,000円です。

レベル1から始まり、道路接続・幸福度60以上・入居率5/6以上を6か月連続で満たすと、最大レベル9まで成長します。1レベルにつき住宅432人分・雇用240人分を持ち、レベル9では定員3,888人・雇用2,160人になります。最大72人/月が入居し、商業・工業税の基準額は1レベル1,560円、維持費は150円/月です。住民税も通常どおり発生します。

商業フロア、生産設備、空中庭園、屋上の浄化設備を描画します。白い排気は浄化済みの無害な排気で、建物自身や周辺住宅に公害を与えません。他の工場の公害は通常どおり受けます。稼働には外部入口につながる道路が必要です。9マスのどこからでも1棟全体を40円で撤去でき、既存のVersion 3セーブと共存します。

`GROWUPTOWN_SUPER_PREVIEW=ultra` を設定して `--smoke-test` を実行すると、レベル1～9の外観プレビューを表示します。

ultraの各側面は、住宅の緑・商業の水色・工業のオレンジの3区画を組み合わせます。既存の各用途16種類の壁面テクスチャを共用し、階・側面ごとに窓、バルコニー、看板、配管などを変えます。棟ごとに色区画の順序・幅、4種類の屋上形状、空中庭園を設ける階が異なります。保存済みの外観IDから決めるため、既存セーブにも反映され、再読込や成長で既存階の外観は変わりません。`GROWUPTOWN_SUPER_PREVIEW=ultra-variants` で、同じレベル6の9棟を並べて違いを比較できます。

## スペシャル：大公園

左の建設パネルには「スペシャル」だけを追加しています。押すとゲーム内の専用ウィンドウが開き、施設を選択できます。施設一覧は1ページ4件のページ切替式で、今後施設が増えても左のパネルは増えません。ウィンドウを開いている間は町の操作と時間進行を停止します。施設を選ぶか「閉じる」またはEscで戻ります。

大公園は **4×4マス、レベル1固定**。建設費5,600円、維持費120円/月です。全16マスが購入済みの空き地なら区画境界をまたいで建設できます。外周のどこかを最初の入口につながる道路に接続すると、外周から縦横の合計距離5マス以内にある住宅の住環境を1棟あたり＋20改善します。super・ultraの住宅部分にも有効で、公園・水域等を含めた住環境の上限は従来どおり＋25です。どの占有マスからでも40円で全体を撤去できます。

外観は次の16種類です。色だけでなく、園路・植栽・施設の配置が異なります。

| 1～4 | 5～8 | 9～12 | 13～16 |
|---|---|---|---|
| 1. 噴水庭園 | 5. ピクニック広場 | 9. 防風林 | 13. 共同菜園 |
| 2. 池と木橋 | 6. 野外劇場 | 10. 彫刻広場 | 14. 湿地と木道 |
| 3. 遊具広場 | 7. バラの花壇 | 11. 運動広場 | 15. 樹木コレクション |
| 4. 林の散策路 | 8. 日本庭園 | 12. 生垣迷路 | 16. 温室庭園 |

設置時には外周6マス以内（斜めを含む）の大公園で未使用の外観を優先し、水辺・住宅・商業・工業・緑地との相性を考慮します。近隣で16種類すべてが使用済みの場合は、隣接する大公園との重複を最優先で避け、近隣で使用数の少ない外観を選びます。入口の向きは設置時に接する道路を参考にします。**外観と向きは設置後に固定**され、周囲の建設・撤去、月の経過、再読込でも変わりません。既存のVersion 3セーブはそのまま読込可能です。

`GROWUPTOWN_SPECIAL_PREVIEW=parks` を設定して `--smoke-test` を実行すると16種類の一覧、`menu` では選択ウィンドウを表示します。通常の町や保存データには影響しません。

## スペシャル：スーパーマーケット

左の「スペシャル」からスーパーマーケットを選び、購入済みの空き地 **4×4マス** に設置します。レベルは1固定。建設費7,200円、維持費160円/月で、道路接続時に64人分の雇用と400円の商業税収基準額を持ちます。実際の税収は従来どおり町の稼働率・税率に応じて変わります。区画をまたいで設置でき、占有マスのどこからでも40円で1棟全体を撤去できます。

最初の入口につながる道路が外周に接すると、店舗から縦横の合計距離5マス以内に次の効果を与えます。対象が複数マスの建物の場合は、その外周までの最短距離で判定します。

- 住宅：買い物の便利さにより住環境＋10。super・ultraの住宅部分にも有効です。公園・水域等を合わせた上限は従来どおり＋25。
- 商業地：商業部分の税収基準額＋20％。super住宅商業地・super工業商業地は1レベルあたり＋80円、ultra複合都市は＋120円です。工業部分の税収は増えません。実際の税収を得るには対象建物も道路に接続する必要があります。
- 複数のスーパーマーケットの範囲が重なっても効果は重複しません。店舗自身には税収ボーナスを付けません。撤去・道路切断時は効果が解除されます。

16種類の外観を用意しました。駐車場・買い物かごの看板・ガラスの入口を備え、建物の形状や屋根、付属施設が異なります。

| 1～4 | 5～8 | 9～12 | 13～16 |
|---|---|---|---|
| 1. 切妻屋根の街角店 | 5. 縞模様の庇の家族向け店 | 9. 柱廊付き市場 | 13. 白いポーチの海辺店 |
| 2. ガラス張りの都市型店 | 6. 二棟をつなぐ店舗 | 10. 時計塔付きレンガ店 | 14. 段状屋根の都市型店 |
| 3. 緑化屋根の自然食品店 | 7. デッキ付き水辺店 | 11. 搬入口付き流通型店 | 15. 青果売場付き食品市場 |
| 4. 連続屋根の倉庫型店 | 8. 中庭を囲む店舗 | 12. 太陽光パネル付き店舗 | 16. 屋上庭園付き店舗 |

設置時に住宅・商業・工業・水辺・緑地との相性を考慮し、外周6マス以内（斜めを含む）のスーパーマーケットで未使用の外観を優先します。近隣で全16種類が使われている場合は、隣接店舗との重複を最優先で避け、近隣の採用数が少ない外観を選びます。入口は設置時の道路の方向を参考にします。**設置後は外観・向きとも固定**で、周辺の変化、時間経過、保存・読込で変わりません。既存のVersion 3セーブも引き続き読み込めます。

`GROWUPTOWN_SPECIAL_PREVIEW=markets` と `--smoke-test` で全16種類、`menu` で大公園とスーパーマーケットの選択画面を確認できます。

## スペシャル：物流センター

「スペシャル」から物流センターを選択して、購入済みの空き地 **4×4マス** に設置します。レベル1固定、建設費8,400円、維持費180円/月。道路接続時は96人分の雇用と600円の税収基準額を持ち、実際の税収は町の稼働率・税率に応じて変わります。区画境界をまたいで設置でき、占有マスのどこからでも40円で全体を撤去できます。

最初の入口につながる道路が外周に接すると、外周から縦横の合計距離5マス以内の **工業・商業部分の税収基準額が＋20％** になります。対象も道路に接続していると税収へ反映されます。複数マスの対象は外周までの最短距離で判定します。

- 通常商業地は1レベルあたり＋20円、工業地は＋32円。
- super住宅商業地は＋80円、super工業地は＋128円、super工業商業地は＋208円、ultra複合都市は＋312円（いずれも1レベルあたり）。住宅部分への直接の効果はありません。
- 複数の物流センターの範囲が重なっても物流効果は1回だけです。スーパーマーケットの効果とは元の税収基準額に対して加算され、商業部分は合計＋40％になります。
- スペシャル施設自身には税収ボーナスを付けません。物流センターは住宅への公害を出しません。撤去・道路切断で周辺効果が解除されます。

外観は次の16種類です。搬入口、トラック、荷物、構内道路を共通の目印に、倉庫の形や屋根、付属設備を変えています。

| 1～4 | 5～8 | 9～12 | 13～16 |
|---|---|---|---|
| 1. 大型配送倉庫 | 5. 太陽光パネル付き | 9. 高層自動倉庫 | 13. 門型クレーン付き |
| 2. 二棟型倉庫 | 6. のこぎり屋根型 | 10. 荷物仕分けセンター | 14. スロープ付き多層型 |
| 3. 事務所棟付き | 7. 積み替えセンター | 11. 冷蔵倉庫 | 15. 中央荷捌き場型 |
| 4. コンテナヤード | 8. 植栽帯付き | 12. 屋上緑化型 | 16. 木調・太陽光併用型 |

設置時の工業・商業・住宅・水辺・緑地との相性を参考にし、外周6マス以内（斜めを含む）の物流センターで未使用の外観を優先します。全16種類が近隣で使われている場合は、隣接する物流センターとの重複回避を最優先にして、近隣で採用数の少ない外観を選びます。搬入口の向きは接する道路を参考に決定します。**設置後の外観・向きは固定**され、周囲の変化や時間経過、保存・読込で変わりません。従来のVersion 3セーブも読み込めます。

`GROWUPTOWN_SPECIAL_PREVIEW=logistics` と `--smoke-test` で全16種類、`menu` でスペシャル一覧を確認できます。

## 公園の外観と接続

公園には林・花壇・噴水・遊具・ピクニック・植え込みの6種類の装飾があります。上下左右に公園を並べると芝生と園路がつながり、共有する境界の縁石がなくなります。隣が道路や大公園の場合も、その方向へ園路を伸ばします。道路自体が入口につながっていなくても園路の見た目は接続します。斜めには接続しません。

配置場所と町のシードで外観を決め、上下左右の公園が増減すると園路と装飾が変化します。同じ隣接状態に戻すと元の外観に戻ります。隣の道路の追加・撤去では園路だけが変化し、装飾は変わりません。月の経過でも変わらず、既存セーブにも対応します。表示範囲の公園だけを軽量な図形で描き、描画のたびに全公園を探索したり画像を再生成したりしません。

公園・大公園が上下左右につながっていれば、そのどこかが最初の入口へ続く道路に面することで、ひと続きの公園全体を道路接続済みとします。途中の公園や道路を撤去すると接続を再判定します。公園経由の接続は公園専用で、住宅・商業地・工業地や別の道路網へは伝わりません。

通常公園の住環境効果は距離3以内に接続時＋10、未接続時も30％の＋3です。大公園は距離5以内に接続時＋20、未接続時＋6となり、占有16マス分を重複加算しません。全体の住環境上限＋25は共通です。大公園の外観・向きは接続状況が変わっても固定されます。

## 水域と橋

水域は隣り合うマスでつながり、細く並べると川、広く並べると池になります。岸は陸との境界だけに描画します。道路接続なしで距離3以内（縦横の合計）の住宅に1マスあたり住環境+10の効果があり、公園等を含めた上限は+25です。

道路の接続が東西の2方向で南北が水域、または南北の2方向で東西が水域なら、自動で橋になります。後から道路・水域を追加・撤去した場合も更新されます。水域の上に道路を引くこともできます。幅の広い川では各道路マスの両脇に水域を並べると、欄干と橋面が連続する長い橋になります。水域上に建設した道路を撤去すると空き地になります。橋に追加料金・追加維持費はありません。

水域は画面付近だけをまとめて描画し、マスごとの画像生成やモデル生成は行いません。Version 3の既存セーブをそのまま読み込めます。
水面には、ゆっくり流れる波の筋と緩やかな明暗のうねりをGPUで描画します。水面は1マス1枚の面のままで、毎フレームの地形再生成や画像転送はありません。波は区画の境界でも連続し、ゲームの停止・倍速に連動します。
水面は地面より0.16マス低く、陸との境界には幅0.14マスの短い斜面があります。橋の下も地面を抜いて水面を通します。画面付近の区画ごとに地形データを保持し、建設・撤去時には影響する区画と境界付近の隣接区画だけを更新します。

## 保存

車は初期道路だけでなく、追加した道路・橋・入口につながっていない道路にも表示され、接続に沿って曲がり、行き止まりでは折り返します。孤立した1マスでは停車表示になります。車は描画用の演出で、現在の道路データには混雑率がないため一定の発生頻度です。カメラ付近だけで生成・更新し、同時表示は最大1,024台。停止・倍速に連動し、車の状態は保存しません。

保存先は DEBUG 時が `GrowUpTown.sln` と同じフォルダー内の `SaveData/city.json`、非 DEBUG 時（Release）が実行ファイル `.exe` と同じフォルダーの `city.json` です。起動時の作業フォルダーには依存しません。スクリーンショットと自己テスト用の一時ファイルも同じ保存先を使用します。`SaveData` は必要時に自動作成します。以前の `%LOCALAPPDATA%\GrowUpTown\city.json` を使う場合は、新しい保存先に手動でコピーしてください。

F5で1スロットに上書き保存します。自動保存はありません。新しい町を始める際は確認画面を表示します。既存の保存ファイルは新規開始では消去しません。

土地と画面外の発展状態を保存するため、保存形式を **Version 3** に更新しました。旧形式（Version 1・2）は読み込めません。新しい町を始めてF5で保存すると、新形式で上書きされます。

## 土地の拡張と画面外の町

最初の土地は24×24マスです。所有地の上下左右に隣接する同サイズの土地を、初回 **1,000,000円**、2回目 **1,500,000円**、3回目 **2,000,000円**、4回目 **2,500,000円** と、購入するたびに50万円ずつ上がる価格で購入できます。最初から所有する区画は購入回数に含めません。購入失敗・キャンセルでは価格は上がりません。保存・読込後も購入済み区画数から次の価格を引き継ぎ、既存のセーブにも適用します。斜めだけの接続は購入できません。購入済みの土地は売却できません。

区画数にゲーム上の固定上限はありません。ただし座標の整数範囲とメモリ等の実行環境には制約があります。カメラ付近を原点にして描くため、遠い土地でも描画の精度を保ちます。描画は画面付近の区画だけを対象にし、空き地の自然物は座標から再生成します。画面外の建物データはメモリ内で圧縮します（ディスクへの逐次退避ではありません）。

画面付近は毎月発展し、画面外は最大12ゲーム月ごとの分散更新、または再表示時に経過分を反映します。その時点の町の条件で経過月を計算する近似方式なので、常時表示した場合と完全に同じ結果にはなりません。画面外の税収・維持費は直近の集計値から毎月計上し、再表示時に二重計上しません。道路の接続判定は建設・撤去時に更新します。

## 階ごとの外観

住宅・商業地・工業地には、それぞれ16種類、合計48種類の壁面デザインがあります。1階につき4面（南 +Z・東 +X・北 −Z・西 −X）を個別に選びます。

- 建設時に1階の4面、レベルアップ時に追加階の4面を決定します。既存階の外観ID・高さ・窓の位置は変わりません。
- 面が向いている方向の道路、公園、工場、周辺建物の高さや空き地を参考にします。
- RCIごとに現在の採用数が最も少ないデザインを候補にし、その中から環境への適合度と町のシード・座標・建設月・階・面による乱数で選びます。同じ階や直下の面との重複も抑えます。
- 環境が一様でも16種類を分散して使用します。周辺が変わっても既存面を選び直しません。IDと町のシードを保存するため、読込後も外観と将来の選択を再現できます。
- 各階の高さは住宅0.52、商業地0.70、工業地0.55で固定です。屋根と煙突は増築後の最上部へ移ります。

## 構成

- `Program.cs`：起動、検証モード
- `City.cs`：建設、道路探索、経済、成長、JSON保存
- `FacadeStyles.cs`：環境と採用数に基づく外観IDの決定・検証
- `BuildingFacades.cs`：48種類の壁面デザイン、共通テクスチャの生成、階・面ごとの描画
- `Game.cs`：3D描画、入力、カメラ、日本語UI
- `WorldChunk.cs`：区画座標、疎な建物データ、画面外データの圧縮と集計
- `TerrainRenderer.cs` / `RoadRenderer.cs`：共通テクスチャによる地面と接続別道路の描画
- `CameraDrag.cs`：右ドラッグのモード固定とカメラ移動
- `WorldTests.cs`：土地購入、区画境界、画面外発展、道路外観、カメラ操作の検証
- `FontLoader.cs`：Windows TTCフォントをメモリ上で読み出す補助
- `SelfTests.cs`：シミュレーションと外観の固定・採用分布・保存の回帰チェック

使用パッケージ：[Raylib-cs 7.0.2](https://www.nuget.org/packages/Raylib-cs/7.0.2)（raylib 5.5用C#バインディング）。NuGet経由でネイティブライブラリも復元されます。
